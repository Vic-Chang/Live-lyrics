# Live Lyrics 滚动歌词

纯前端网页程序（HTML + CSS + JavaScript，无需安装、无需后端）。

## 功能

- **搜索歌词**：输入歌名、歌手或一句歌词搜索（资料来源：[LRCLIB](https://lrclib.net)，免费、免 API key）。
- **语音搜索**：按 🎤 直接说出歌名，可选择识别语言（中文台湾/大陆、粤语、英文、日文、韩文）。
- **同步滚动歌词**：歌词跟着歌曲进度自动滚动，当前这句会放大高亮并置中。
- **歌词大小**：用 `A−` / `A+`、滑杆，或在歌词区按 `Ctrl + 滚轮` 缩放（会记住设定）。
- **点歌词跳播**：点任何一行歌词，就会从那一段开始播放。
- **音乐来源**：
  - 选择本机音乐档（mp3、m4a…）→ 真正播放音乐，歌词同步滚动。
  - 没有音乐档也可以：用「歌词计时器」播放，歌词一样会滚动、可点击跳转。
  - 选音乐档时如果还没选歌，会用档名自动搜索歌词。
- **同步微调**：歌词与音乐对不准时，用右下角 `−` / `+` 每次调 0.5 秒。
- 快捷键：`空白键` 播放/暂停，`←` / `→` 倒退/快进 5 秒。

## 使用方式

直接用浏览器打开 `index.html`，或用任一静态服务器：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

> 语音输入需使用 Chrome、Edge 或 Safari，且需允许麦克风权限。
> Chrome 的麦克风权限只在 `https://` 或 `http://localhost` 下可用，
> 建议用上面的方式启动，或部署到 GitHub Pages。
